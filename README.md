# Simple Interest Calculator

## 📌 Project Description

The **Simple Interest Calculator** is a simple program that calculates the simple interest and total amount based on the principal amount, interest rate, and time period.

This project is designed to demonstrate the basic concept of simple interest calculation and basic programming logic.

## 🧮 Formula

The simple interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

The total amount is calculated as:

**Total Amount = Principal + Simple Interest**

### Where:

* **Principal (P):** The initial amount of money.
* **Rate (R):** The annual interest rate in percentage (%).
* **Time (T):** The time period in years.

## 💡 Example

For example:

* Principal = $1,000
* Rate = 5%
* Time = 2 years

Simple Interest:

**(1,000 × 5 × 2) / 100 = $100**

Total Amount:

**$1,000 + $100 = $1,100**

Therefore:

* **Simple Interest = $100**
* **Total Amount = $1,100**

## 🚀 Features

* Calculate simple interest.
* Calculate the total amount.
* Easy and simple to use.
* Suitable for beginners learning programming.

## 📥 Input

The calculator requires three inputs:

1. Principal amount
2. Interest rate (%)
3. Time period (years)

## 📤 Output

The calculator displays:

* Simple Interest
* Total Amount
